# بلال موبائل شاپ - پی ایچ پی (PHP) اور مائی ایس کیو ایل (MySQL) بیک اینڈ سیٹ اپ گائیڈ

یہ بیک اینڈ **InfinityFree (cPanel)** اور **Hostinger (hPanel)** دونوں کے لیے خصوصی طور پر تیار کیا گیا ہے۔ اس کے ذریعے آپ کا سارا ڈیٹا آپ کے اپنے مائی ایس کیو ایل ڈیٹا بیس میں محفوظ ہوگا اور فائر بیس کی روزانہ 50,000 ریڈز کی حد (Limit) کا جھنجھٹ مکمل طور پر ختم ہو جائے گا۔

---

## 🚀 طریقہ نمبر 1: InfinityFree (مفت ہوسٹنگ / cPanel) پر لگانے کا طریقہ

### مرحلہ 1: نیا MySQL ڈیٹا بیس بنائیں
1. اپنے **InfinityFree vPanel / cPanel** میں لاگ ان ہوں۔
2. **"MySQL Databases"** پر کلک کریں۔
3. ایک نیا ڈیٹا بیس بنائیں، مثلاً: `balal_db`۔
4. وہاں سے درج ذیل 4 چیزیں نوٹ کر لیں:
   - **MySQL Hostname**: (مثلاً: `sql205.epizy.com` یا `sql101.infinityfree.com`)
   - **MySQL Database Name**: (مثلاً: `epiz_38123456_balal_db`)
   - **MySQL Username**: (مثلاً: `epiz_38123456`)
   - **MySQL Password**: (آپ کا vPanel اکاؤنٹ پاس ورڈ)

### مرحلہ 2: ٹیبلز بنائیں (phpMyAdmin)
1. InfinityFree کنٹرول پینل میں **"phpMyAdmin"** بٹن پر کلک کریں۔
2. بائیں جانب اپنے نئے ڈیٹا بیس کے نام پر کلک کریں۔
3. اوپر والے مینو سے **"Import"** منتخب کریں۔
4. "Choose File" پر کلک کر کے اس فولڈر میں موجود **`db.sql`** فائل منتخب کریں۔
5. نیچے **"Go"** یا **"Import"** دبا دیں۔ چند سیکنڈ میں تمام ٹیبلز (پراڈکٹس، سیلز، کیش لیجر، سپلائرز) بن جائیں گے۔

### مرحلہ 3: `config.php` فائل سیٹ کریں
اپنے کمپیوٹر یا cPanel فائل مینیجر میں **`config.php`** فائل کو کھولیں اور اپنی ڈیٹا بیس معلومات لکھ دیں:
```php
$DB_HOST = 'sql205.epizy.com';              // آپ کا MySQL Hostname
$DB_NAME = 'epiz_38123456_balal_db';        // آپ کا ڈیٹا بیس نام
$DB_USER = 'epiz_38123456';                 // آپ کا یوزر نیم
$DB_PASS = 'AapKaPassword';                 // آپ کا پاس ورڈ
```
فائل کو محفوظ (Save) کر دیں۔

### مرحلہ 4: فائلیں اپلوڈ کریں
1. InfinityFree میں **"Online File Manager"** کھولیں (یا FileZilla استعمال کریں)۔
2. **`htdocs`** فولڈر کے اندر جائیں۔
3. وہاں ایک نیا فولڈر بنائیں جس کا نام **`api`** رکھیں: `htdocs/api`۔
4. اس `api` فولڈر کے اندر درج ذیل فائلیں اپلوڈ کر دیں:
   - `config.php`
   - `.htaccess`
   - `api/` فولڈر کی تمام فائلیں (`health.php`, `sync.php`, `products.php`, `sales.php`, `transactions.php`)
   
### مرحلہ 5: براؤزر میں ٹیسٹ کریں
براؤزر میں اپنے ڈومین کا لنک کھولیں:
`http://yourdomain.infinityfreeapp.com/api/health.php`
اگر اسکرین پر سبز رنگ میں `"status": "HEALTHY"` اور `"Database Connected Successfully"` لکھا آ جائے تو مبارک ہو، آپ کا سرور بالکل تیار ہے!

## ⚡ طریقہ نمبر 2: Hostinger (hPanel) پر لگانے کا طریقہ

### مرحلہ 1: ڈیٹا بیس بنائیں
1. Hostinger **hPanel** کھولیں۔
2. بائیں مینو سے **Databases -> Management** پر جائیں۔
3. **"Create New MySQL Database"** پر کلک کریں:
   - ڈیٹا بیس نام لکھیں (مثلاً: `balal_db`)
   - یوزر نیم اور مضبوط پاس ورڈ درج کریں اور **"Create"** پر کلک کریں۔

### مرحلہ 2: `db.sql` امپورٹ کریں
1. ہوسٹنگر میں **"Enter phpMyAdmin"** پر کلک کریں۔
2. ڈیٹا بیس منتخب کر کے اوپر **"Import"** دبائیں۔
3. **`db.sql`** فائل اپلوڈ کر کے **"Go"** دبا دیں۔

### مرحلہ 3: فائلیں اپلوڈ کریں اور `config.php` ایڈٹ کریں
1. Hostinger کے **"File Manager"** میں جائیں۔
2. `public_html` کے اندر جائیں اور نیا فولڈر **`api`** بنائیں: `public_html/api`۔
3. تمام فائلیں وہاں اپلوڈ کریں۔
4. `config.php` میں Hostinger کی معلومات درج کریں:
```php
$DB_HOST = 'localhost';             // Hostinger پر ہمیشہ localhost ہوتا ہے
$DB_NAME = 'u123456789_balal_db';   // آپ کا ڈیٹا بیس نام
$DB_USER = 'u123456789_balal_user'; // آپ کا یوزر نیم
$DB_PASS = 'AapKaHostingerPassword';// آپ کا پاس ورڈ
```

## 📱 ایپ کو اپنے PHP سرور سے جوڑنے کا طریقہ:
1. اپنے موبائل شاپ سافٹ ویئر کو کھولیں۔
2. اوپر ٹاپ بار میں **"PHP سرور سیٹنگز"** (یا Settings -> PHP Server) پر کلک کریں۔
3. وہاں اپنے سرور کا API لنک درج کریں، مثلاً:
   - `https://my-shop.infinityfreeapp.com/api` یا `https://myshop.com/api`
4. **"ٹیسٹ کنکشن (Test Connection)"** دبائیں۔
5. جیسے ہی کنکشن اوکے ہو جائے، **"تمام ڈیٹا سنک کریں (Sync All Data Now)"** پر کلک کر دیں۔
   آپ کا سارا لوکل انوینٹری، فونز اور کیش ریکارڈ ایک سیکنڈ میں آپ کے اپنے MySQL ڈیٹا بیس میں چلا جائے گا!

## 💡 فوائد:
* **لامحدود ڈیٹا (Zero Limits)**: فائر بیس کی کوئی 50,000 ریڈز والی لمٹ نہیں۔
* **مکمل ملکیت**: آپ کا ڈیٹا آپ کے اپنے ہوسٹنگر یا انفینیٹی فری پر محفوظ ہے۔
* **100% آف لائن سپورٹ**: انٹرنیٹ بند بھی ہو جائے تو بھی دکان پر بل کٹتے رہیں گے، جیسے ہی نیٹ آئے گا ڈیٹا خود بخود سنک ہو جائے گا۔
