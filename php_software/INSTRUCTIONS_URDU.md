# بلال موبائل شاپ - پی ایچ پی (PHP) اور مائی ایس کیو ایل (MySQL) مکمل سافٹ ویئر گائیڈ

یہ سافٹ ویئر **InfinityFree (cPanel)** اور **Hostinger (hPanel)** دونوں کے لیے مکمل طور پر تیار کیا گیا ہے۔
اس میں دکان کا پورا نظام (POS، اسٹاک، کیش، ادھار، IMEI ٹریکنگ، شناختی کارڈ فوٹو والٹ اور کلاؤڈ بیک اپ) موجود ہے۔

---

## 📁 فولڈر کا ڈھانچہ (Folder Structure):
- `backend/`: ڈیٹا بیس کنکشن (`config.php`)، سیکیورٹی، ہیڈر اور سائڈبار
- `api/`: موبائل ایپ اور REST API کے لیے ڈیٹا سنک اینڈ پوائنٹس
- `dashboard/`: مین ڈیش بورڈ اور روزانہ تجزیات
- `pos/`: تیز ترین بارکوڈ بلنگ اور رسید پرنٹنگ
- `sales_ledger/`: تمام سیلز اور منافع کا مکمل کھاتہ
- `purchase_register/`: پرانے موبائلز کا خرید رجسٹر اور قانونی ایگریمنٹ
- `inventory/`: موبائلز اور لوازمات کا اسٹاک
- `mobile_ledger/`: موبائل فونز کی IMEI وارنٹی اور اسٹیٹس
- `easypaisa_ledger/`: ایزی پیسہ، جاز کیش اور کیش دراز
- `customer_khata/`: کسٹمر ادھار کھاتہ و واٹس ایپ رسید
- `supplier_khata/`: ہول سیل ڈیلرز و سپلائرز کھاتہ
- `photo_vault/`: کسٹمرز کے شناختی کارڈ کی تصاویر کا والٹ
- `barcode_studio/`: تھرمل بارکوڈ پرنٹنگ اسٹوڈیو
- `reports/`: نفع و نقصان کی تفصیلی رپورٹس
- `gdrive/`: گوگل ڈرائیو کلاؤڈ بیک اپ اور فائل مینیجر
- `admin/`: اسٹاف اکاؤنٹس، پِن اور پرمیشنز
- `settings/`: دکان کی پروفائل اور ڈیٹا بیک اپ
- `db.sql`: ڈیٹا بیس بنانے کے لیے ریڈی فائل

---

## 🚀 انسٹالیشن کا طریقہ (cPanel / Hostinger / InfinityFree):

### مرحلہ 1: نیا MySQL ڈیٹا بیس بنائیں
1. اپنے cPanel یا Hostinger میں **MySQL Databases** پر جائیں۔
2. نیا ڈیٹا بیس بنائیں (مثلاً `balal_pos_db`)۔
3. یوزر نیم اور پاس ورڈ بنا کر ڈیٹا بیس کے ساتھ منسلک کریں اور All Privileges دیں۔

### مرحلہ 2: `db.sql` امپورٹ کریں
1. **phpMyAdmin** کھولیں۔
2. اپنے ڈیٹا بیس پر کلک کر کے اوپر **Import** دبائیں۔
3. `db.sql` فائل اپلوڈ کر کے **Go** پر کلک کریں۔

### مرحلہ 3: `backend/config.php` ایڈٹ کریں
`backend/config.php` فائل میں اپنے ڈیٹا بیس کی تفصیلات لکھ دیں:
```php
$DB_HOST = 'localhost';             // یا InfinityFree کا sql host
$DB_NAME = 'your_database_name';    // آپ کا ڈیٹا بیس نام
$DB_USER = 'your_database_user';    // آپ کا یوزر نیم
$DB_PASS = 'your_database_password';// آپ کا پاس ورڈ
```

### مرحلہ 4: براؤزر میں سافٹ ویئر چلائیں
فائلیں اپلوڈ کرنے کے بعد براؤزر میں اپنا لنک کھولیں:
`http://yourdomain.com/php_software/` یا `http://yourdomain.com/`
اور ڈیفالٹ ماسٹر پِن **6242** کے ذریعے لاگ ان ہوں۔
